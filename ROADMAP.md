ROADMAP.md — План разработки сайта по умному дому
Этап 1: Каркас проекта, дизайн-система и инфраструктура (Win 11)
Инициализация Next.js (App Router, TypeScript strict), настройка output: 'standalone' и создание .gitattributes (LF line endings для кроссплатформенности Windows → Linux Docker).
Настройка Tailwind CSS: конфигурация тёмной палитры, кастомных свечений (neon/warm glow) и локальных кириллических шрифтов (включая шрифты в public/fonts/ для будущего PDF).
Настройка тестового фреймворка Vitest + React Testing Library и кроссплатформенных скриптов в package.json (vitest run без watch-зависаний в PowerShell).
Создание базового Layout: адаптивная шапка (Header) с навигацией, футер с контактами и ссылками на ботов.
Верстка базовой главной страницы (/) с анимированным Hero-блоком на Framer Motion.
Unit-тесты на рендер навигации и базовых UI-компонентов.
Этап 2: Интерактивный калькулятор и каталог оборудования (Core Logic)
Создание справочника оборудования и коэффициентов (src/lib/calculator/catalog.ts) с разделением по брендам (Aqara, Sonoff, Sprut, Tuya Zigbee) и хабам (Home Assistant, Sprut.hub, Яндекс Алиса).
Реализация чистой бизнес-логики расчёта спецификации (количество устройств, стоимость оборудования, стоимость монтажа и пусконаладки) в src/lib/calculator/.
Написание полного набора unit-тестов на математику калькулятора, коэффициенты брендов и граничные случаи (100% покрытие src/lib/calculator/).
Разработка страницы /calculator с интерактивным выбором объекта, систем и бренда оборудования, мгновенным пересчётом и детализацией спецификации.
Компонентные тесты на взаимодействие пользователя с калькулятором.
Этап 3: Генерация клиентской PDF-сметы
Интеграция @react-pdf/renderer и регистрация локальных кириллических шрифтов (без запросов к внешним CDN).
Верстка шаблона коммерческого предложения / PDF-сметы (src/components/pdf/EstimatePdfDocument.tsx): шапка компании, параметры объекта, таблица оборудования (с указанием брендов Aqara/Sonoff/Sprut), стоимость работ, итоговая сумма и контакты.
Добавление кнопки «Скачать PDF-смету» на страницу /calculator с индикатором генерации.
Написание тестов на формирование структуры данных для PDF-документа и корректный рендер компонента генерации.
Этап 4: Многостраничный контент и динамические блоки
Создание страницы /services с детальным разбором систем (освещение, климат, шторы, датчики протечки/безопасности), сравнением экосистем и интерактивным переключением сценариев («Утро», «Я ушёл», «Кино», «Ночь»).
Создание страницы /portfolio с карточками реализованных объектов (состав оборудования Aqara/Sonoff/Sprut, бюджет, сроки, фото/схемы).
Создание страницы /contacts и модальных окон быстрого заказа расчёта.
Добавление на главную страницу интерактивной схемы работы беспроводного умного дома (Zigbee/Matter mesh-сеть, локальный хаб, голосовое управление) и блока используемых брендов.
Этап 5: Бэкенд-интеграции (Боты, заявки) и безопасность
Создание серверных API-роутов (app/api/lead/route.ts) с валидацией через Zod.
Интеграция отправки заявок и детализированной сметы из калькулятора в Telegram-бота (с модульной архитектурой под подключение MAX-бота).
Реализация защиты от спама: honeypot-поля в формах и rate-limiting на API.
Экранирование спецсимволов в тексте заявок для защиты от инъекций в разметку бота.
Написание тестов на API-роуты (валидные данные, ошибки валидации, срабатывание антиспама, мок отправки в бота).
Этап 6: SEO, оптимизация и подготовка к деплою (Vercel → РФ VPS)
Настройка динамических мета-тегов (Metadata API в Next.js), OpenGraph, sitemap.xml и robots.txt.
Оптимизация изображений (next/image), проверка Lighthouse (Performance, Accessibility, SEO > 90) и проверка prefers-reduced-motion.
Подготовка Dockerfile и docker-compose.yml (в связке с Nginx) для переноса с Vercel на российский VPS.
Финальный прогон всех тестов (npm run test -- --run), линтера (npm run lint) и production-сборки (npm run build).
